## ✨ Overview

**Local Event Finder App** is a Flutter-based mobile application that helps users discover events around them using location services and interactive UI.

It provides a smooth experience for browsing, searching, and viewing event details in real-time.

---

## 🚀 Key Features

* 🔍 Search and discover nearby events
* 📍 Location-based event suggestions
* 🗺️ View event locations on map
* 📅 Detailed event information
* 📱 Fully responsive UI (mobile & tablet)
